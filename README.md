# بوت تليجرام — خدمات الملكي للرشق 👑

بوت متجر متصل مباشرة بموقعك https://app1-fmzc.onrender.com (نفس الحسابات والرصيد والطلبات).

## للمستخدمين
- تسجيل دخول / إنشاء حساب بنفس حساب الموقع
- تصفح الخدمات حسب القسم والشراء (رابط + كمية + تأكيد وخصم الرصيد)
- عرض الرصيد والطلبات وحالتها
- شحن الرصيد والدعم عبر واتساب
- زر يفتح الموقع كاملاً داخل تليجرام (Mini App)

## للأدمن (يظهر تلقائياً لحساب الأدمن)
- 🔔 إشعار فوري بكل طلب جديد مع أزرار: بدء التنفيذ / مكتمل / إلغاء وإرجاع الرصيد
- 💵 شحن رصيد أي مستخدم
- 👥 عرض المستخدمين
- ➕🗑️ إضافة وحذف المنتجات (تظهر في الموقع والبوت معاً) — يتطلب تحديث السيرفر في ADD_TO_SERVER.md

## الإعداد
1. من @BotFather في تليجرام: `/newbot` واحصل على التوكن.
2. متغيرات البيئة:
   - `BOT_TOKEN` = التوكن (إجباري)
   - `SITE_URL` = https://app1-fmzc.onrender.com (اختياري)
   - `SUPPORT_WHATSAPP` = 967734591441 (اختياري)
3. التشغيل: `npm start` (Node 18 أو أحدث، بدون أي مكتبات).

## الرفع على Render
New → Web Service → Build: `npm install` — Start: `npm start` — أضف `BOT_TOKEN`.
البوت يستخدم Webhook تلقائياً على Render فيستيقظ مع كل رسالة حتى في الخطة المجانية.
